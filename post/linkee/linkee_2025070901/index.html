👋 링키(Linkee) 사용 설명서

안녕하세요!
링키(Linkee) 는 여러분이 자주 쓰는 사이트 주소를 한 곳에 모아서,
쉽게 꺼내 보고 친구나 가족에게도 공유할 수 있는 앱입니다.

📱 이런 분들께 추천드려요!

  • 인스타그램, 유튜브, 블로그 등을 한 곳에 모아보고 싶은 분
  • 자녀나 친구에게 내 사이트 모음을 보여주고 싶은 분
  • 복잡한 앱은 싫고, 단순하고 쉬운 앱을 찾는 분

✅ 링키는 이렇게 사용해요

1. 앱 시작하기

  • 앱을 열고, 회원가입 또는 로그인을 해주세요.
  • 이름, 이메일, 비밀번호만 입력하면 끝! 45

2. 내 링크 추가하기

  • 아래쪽에 있는 [➕ 링크 추가] 버튼을 눌러주세요.
  • 어떤 사이트인지 선택하고(예: 유튜브),
    • 📌 링크 제목 (예: 우리 교회 유튜브)
    • 🔗 주소 (예: https://youtube.com/ …)
    • 😊 이모지(그림 이모티콘)를 선택해 입력하면 저장됩니다.

3. 친구나 가족에게 보여주기

  • 아래에 있는 [내링키 공유] 버튼을 누르면
    자동으로 주소가 복사돼요.
  • 복사한 주소를 카카오톡, 문자 등으로 보내면
    상대방은 내 링크 모음을 볼 수 있어요.

4. 다시 내 화면으로 돌아오기

  • 다른 사람의 링크 화면을 보고 있다면,
    [전환] 버튼을 눌러서
    다시 내 링크 화면으로 돌아올 수 있어요.

💡 기억해두세요

  • 앱은 처음 한 번만 로그인하면 자동으로 기억해줘요.
  • 사용 중 궁금한 점은 언제든지 문의해 주세요! (yw2a.service@gmail.com )

🎁 예시 화면

  • 📷 예: 유튜브, 블로그, 인스타 등을 보기 좋게 정리
  • 📲 친구에게 링크 보내기 = 명함처럼 깔끔하게!

지금 바로 나만의 링크 모음을 만들어보세요.
